# FreshFold Laundry Services

A responsive laundry-service website built with:

- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

## Included functionality

- Responsive navbar and hero section
- Service achievements section
- 15 laundry services
- Dynamic Add Item / Remove Item cart
- Dynamic total amount
- Booking form validation
- Booking success message
- Newsletter subscription interaction
- Responsive mobile layout
- Footer with links and contact information
